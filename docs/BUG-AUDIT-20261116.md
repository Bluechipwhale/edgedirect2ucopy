# Bug audit — 16 November 2026

This source release corrects three shopping issues:

- Product options now share their SKU's available stock in the bag. Adding another option or increasing a line cannot exceed the remaining quantity held across all options. Unsuccessful additions no longer report that an item was added.
- Older saved bags that exceed current availability show a stock explanation and require a quantity correction before checkout. The server's existing transactional stock checks remain authoritative.
- Product galleries deduplicate the primary image and ignore empty gallery entries, preventing repeated thumbnails and duplicate React keys. Stored product photos are preserved.

The release also includes the previously prepared homepage selection: the twelve older eligible products plus the featured Soup MAXI and Fish MAXI imports. Other imported foods remain available in their category and the full shop. The live homepage observed at the start of this audit was still serving the earlier selection, so this needs a source redeployment rather than a rebuild of previously uploaded files.

The audit checked live storefront and sign-in pages, portal entry guards, public database health, catalogue images, private read APIs and production dependency advisories. Local automated tests cover admin product editing/deletion/restoration, authentication and password recovery, cart/checkout, offline app behavior, driver GPS rules and reports. Real customer orders, charges, refunds and email delivery are not generated by this audit.

Functional browser tests use a local image fixture for the unrelated demo stock-photo CDN. This removes network timeouts from admin/search tests without replacing the production product images or bypassing application assertions. Navigation assertions wait for the destination product page before checking its option controls.

Deployment evidence belongs in the local audit outputs. Source checks alone do not mean that Hostinger is running the new release. After redeployment, verify the primary homepage product list and the deduplicated Soup/Fish galleries; keep the separate Vercel backup unchanged.
